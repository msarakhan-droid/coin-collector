# Збирач монет

«Збирач монет» — браузерна мінігра, створена за допомогою HTML, CSS та JavaScript. Гравець керує блакитним колом стрілками клавіатури або клавішами WASD і збирає жовті монети. За кожну монету нараховується одне очко та відтворюється короткий звуковий ефект. Червоне коло переслідує гравця з початковою швидкістю 120 пікселів за секунду. Після кожних п’яти зібраних монет швидкість ворога збільшується на 10 пікселів за секунду. Коли ворог торкається гравця, гра завершується та показує підсумковий рахунок і час. Для запуску достатньо відкрити файл `index.html` у браузері або перейти на опубліковану сторінку GitHub Pages.

## Запуск

Перейменуйте `coin_collector.html` на `index.html` для публікації через GitHub Pages. У GitHub відкрийте **Settings → Pages → Deploy from a branch → main / (root) → Save**.
